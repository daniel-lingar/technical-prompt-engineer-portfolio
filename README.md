# Technical Prompt Engineer & AI Evaluation Specialist

This repository contains a screening-focused application profile and a static portfolio built around **prompt architecture, rubric-based evaluation, Markdown documentation, and asynchronous systems work**.

## Live Portfolio

The public portfolio is published at [daniel-lingar.github.io/technical-prompt-engineer-portfolio](https://daniel-lingar.github.io/technical-prompt-engineer-portfolio/).

## Repository Contents

| File | Purpose |
| --- | --- |
| [`APPLICATION_PROFILE.md`](./APPLICATION_PROFILE.md) | Copy-ready, plain-text-compatible application profile and resume. |
| [`CURRICULUM.md`](./CURRICULUM.md) | A 75-session flat-file curriculum demonstrating information architecture and evidence-oriented study. |
| [`PROMPT_SCHEMAS.md`](./PROMPT_SCHEMAS.md) | Inspectable prompt and evaluation schemas. |
| [`ideas.md`](./ideas.md) | Design system and editorial approach for the static portfolio. |

## Local Development

Run `pnpm dev` from the repository root, then open the local URL shown in the terminal. The portfolio is a static React site designed to be publishable on a GitHub Pages-compatible host after its production build is generated.

## Before Submitting Applications

Replace `[EMAIL]` in `APPLICATION_PROFILE.md` with the preferred application contact address. The profile already links to the verified GitHub account and published curriculum; review all role and experience statements for accuracy before submission.
