# What Really Happened — 75-Session Curriculum

This is a **portfolio-ready curriculum architecture** for asynchronous study. It demonstrates how a flat-file Markdown project can organize analytical work, source handling, evaluation criteria, and clear session artifacts. The curriculum is arranged in five fifteen-session modules so every stage leads to a tangible record a reviewer can inspect.

| Module | Sessions | Purpose | Primary Artifact |
| --- | ---: | --- | --- |
| I. Framing the Record | 01–15 | Establish source boundaries and initial claims | Source map and claim register |
| II. Extracting Evidence | 16–30 | Move from raw materials to normalized observations | Evidence ledger |
| III. Testing the Narrative | 31–45 | Identify conflicts, assumptions, and missing context | Contradiction log |
| IV. Documenting Judgment | 46–60 | Convert findings into reproducible explanations | Annotated synthesis |
| V. Publishing the Audit Trail | 61–75 | Package the work for independent review | Static portfolio dossier |
