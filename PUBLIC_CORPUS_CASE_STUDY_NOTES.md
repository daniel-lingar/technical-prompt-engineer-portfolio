# Public Corpus Case Study Notes

## Candidate Sources

| Public site | Potential value for a grounded evaluation case study | Initial handling decision |
| --- | --- | --- |
| [Horner Archive](https://daniel-lingar.github.io/horner-archive/) | Contains clearly identified public-history document types, including land patents, census records, military records, funerary records, survey notes, maps, and source documentation. It supports factual extraction tasks with traceable source categories. | **Preferred primary source.** Use small, publicly available source excerpts and factual fields such as document type, person, date, place, record institution, and source status. |
| [From the Storm to the Fire working manuscript](https://daniel-lingar.github.io/72026FROMTHESTORMTOTHEFIRE/manuscript.html) | Demonstrates long-form manuscript structure and revision provenance. It contains highly personal discussion of trauma, substance use, violence, grief, and suicide. | **Do not use as an initial evaluation dataset.** Retain it only as evidence of source-to-publication workflow and use no personal passages in public test cases. |
| [Capitol Contracts](https://daniel-lingar.github.io/capitol-contracts/) | Provides bounded public documentation, organizational statements, capability language, and implementation framing. | Possible secondary source for scope-boundary and structured-document classification tasks. |
| [WRH Master Curriculum](https://daniel-lingar.github.io/wrh-master-curriculum/) | Provides structured curriculum sessions, public implementation navigation, and non-clinical scope boundaries. | Possible secondary source for document metadata or citation-grounding tasks, subject to a final content review. |
| [The Rescue Boat](https://daniel-lingar.github.io/rescue-boat/) | Demonstrates public article publishing and canonical content controls but includes sensitive trauma and addiction subject matter. | Reserve for methodology documentation rather than test inputs in the first public case study. |

## Recommended First Task

Use the Horner Archive to create a **source-card extraction and grounding evaluation**. Each real public case should reference a short source excerpt and require a constrained JSON record with documentary fields only. The evaluation should score field-level factual accuracy, valid-schema rate, supported-vs-unsupported claims, correct abstention for missing data, and refusal of instruction-injection strings embedded in source text.

## Boundaries

The first dataset must use only publicly available, non-sensitive archive excerpts with stable source URLs. It must not include personal memoir passages, clinical claims, legal conclusions, or fabricated labels. Each gold field needs a human-reviewed source citation, and all metrics must be generated by the included evaluation code.

## Additional Public-Site Observations

The Capitol Contracts landing page exposes stable organizational and resource fields such as legal name, primary service area, NAICS code, capability framing, and explicitly bounded non-clinical scope language. These can support a secondary classification task but should not be used to infer legal, medical, ownership, or certification conclusions beyond the stated text.

The WRH landing page exposes structured system metadata—77 sessions, four parts, named entry paths, intended audiences, and explicit non-clinical/no-disclosure/safety-aware boundaries. It can support citation-grounding and metadata-extraction cases only where every expected field is directly visible in the selected public source.

The Rescue Boat site confirms an explicit version lock, a ten-article public edition, distinct reader paths, a relationship to the WRH and Capitol Contracts repositories, and a non-clinical scope boundary. Its subject matter remains sensitive, so use it as evidence of canonical publication controls and reader-oriented information architecture rather than as input data for the initial factual extraction evaluation.
